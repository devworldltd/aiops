## 상승 근거

minor — **새 config 키**(`ai_chat_url` · `ai_chat_tenant`)가 생겼다. 체크리스트 §3 의 "새 config 키" 기준에 해당한다. 스킬·에이전트 수는 35·26 그대로다.

처음에는 patch 로 볼 뻔했다. 주소 문자열 교체가 눈에 띄는 변화라서다. 그러나 이 릴리스의 실질은 **설정 표면이 넓어진 것**이고, 소비자가 `.claude/config.json` 에 키를 넣어야 효과를 보는 종류의 변경이다.

## 무엇이 바뀌나 — 허브 주소를 설정에서 읽는다

ai-chat 허브 기준 주소가 커스텀 도메인 `https://ai-chat.devworld.co.kr` 로 통일됐다. 같은 Worker·같은 D1 이라 토큰·데이터는 그대로이고 호스트명만 바뀐다. 옛 `workers.dev` 주소도 계속 살아 있어 장애 대응이 아니다.

더 중요한 건 주소를 **어디서 읽는가**다. `/aiops:ai-chat` §0-1 은 `.claude/config.json` → `AI_CHAT_URL` → 사용자 확인 순으로 해석하도록 규정해 놓고, 정작 이 레포에 `config.json` 이 없어 **해석 경로가 둘 다 비어 있었다.** 규약을 실행해 보니 `CLAUDE.md` 본문을 읽어야 진행되는 상태였다 — 규정과 실제가 갈려 있었고, 실행해 보기 전까지는 드러나지 않았다.

이제 설정 파일이 정본이다. 주소가 또 바뀌면 문서가 아니라 `.claude/config.json` 한 곳만 고친다.

## 소비자가 할 일

프로젝트에 아래를 넣으면 된다. 넣지 않아도 동작한다 — 기본값이 새 주소다.

```json
{ "ai_chat_url": "https://ai-chat.devworld.co.kr", "ai_chat_tenant": "devworld" }
```

## 이번 릴리스의 부수 소득 — 무시 정책

`.gitignore` 에 `.claude` 항목이 아예 없어 세션·캐시 같은 개인 산출물까지 커밋 가능한 상태였다. `.claude/*` + `!.claude/config.json` 으로 바꿨다.

`!.claude/config.json` 한 줄만 추가해서는 동작하지 않는다. 디렉터리 자체(`.claude/`)를 제외하면 git 이 그 하위를 훑지 않아 부정 패턴이 평가되지 않기 때문이다. 내용(`.claude/*`)을 제외해야 한다.
