## 이번 릴리스의 내용 — release.sh 결함 둘

### 1. `git push` 실패를 확인하지 않았다

공개본 push 가 403 을 두 번 맞았는데 `✓ 공개본 게시 완료` 를 출력했다. 사내 태그는 나갔고 공개본만 안 나간 상태를 아무도 몰랐다.

`push` **4곳 전부** 종료 코드를 확인한다(사내 태그·사내 `latest`·공개본 `main`·공개본 태그). 실패 시 **무엇이 이미 나갔는지**와 **복구 명령**(`--publish-only <TAG>`)을 stderr 로 안내하고 `1` 로 끝낸다.

### 2. 계획 출력이 실제 나갈 커밋과 달랐다

`--publish-only` 는 태그를 새로 만들지 않고 기존 태그의 트리를 게시하는데, 계획 줄은 `main` 을 찍고 있었다. v1.13.1 게시에서 계획은 `cc4744d`, 실제로 나간 것은 `9d7b1db` 였다. **출력만 보고는 무엇이 게시됐는지 알 수 없었다.**

- publish 모드는 기존 태그 커밋을 찍고 `(기존 태그 — 새로 만들지 않음)` 을 덧붙인다
- `main` 이 태그보다 앞서면 **몇 커밋 앞서는지 경고**하고, 새 patch 릴리스를 안내한다(태그 이동 금지)

이 경고가 있었다면 위의 노트/내용 불일치를 태그 전에 잡았다.
