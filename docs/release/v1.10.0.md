## 이번 릴리스의 핵심

CLI 프로젝트가 E2E 단계를 **실제로 통과할 수 있게** 됐다. 이전에는 `dev-e2e` 가 CLI 골격을
만들지 않았고 `qa-e2e` 의 게이트가 Playwright 설치를 강제해, CLI 플랫폼은 항상 환경 오류로
막혔다. `qa-e2e.md` 는 **바이트 단위로 변경하지 않고** 별도 에이전트(`qa-e2e-cli`)를 두어
기존 웹 경로의 무회귀를 증명이 아니라 구조로 보장했다.

러너의 판정 불변식(#41):
- 통과로 판정하려면 **실제로 통과한 테스트가 1건 이상** 있어야 한다
- 시나리오 디렉토리가 비면 `E2E_ENV_ERROR=cli_scenario_dir_empty:<mode>` (exit 2)
- TAP 파싱 실패 시 PASS 로 폴백하지 않는다 (exit 2)
- 전부 SKIP 이면 `failed==0` 이어도 **PASS 가 아니다** (exit 1)
