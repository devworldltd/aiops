## #38 `--dry-run` 이 접근 확인을 건너뛰고 0 으로 통과했다

PyJWT 가 없으면 `verify_access` 가 경고 한 줄 찍고 `return` 했다.

```
⚠️  PyJWT 가 없어 API 접근 확인을 건너뜁니다
dry-run — 아카이브·업로드하지 않고 종료합니다.
종료코드=0
```

**`--dry-run` 의 목적이 접근 확인인데 그 확인을 못 한 채 성공으로 끝났다.**
`android-release` 는 같은 자리에서 실제 호출로 막는다 — **같은 플래그가 두 스킬에서 다르게
동작했다.**

zen-koi 가 (A)안(직접 서명)을 권했고 그것이 맞다. `cryptography` 만으로 ES256 JWT 를 만든다.
의존성이 하나 줄고 **건너뛸 이유도 사라진다** — (B)안(의존성 유지 + 종료 코드 2)은 여전히
"확인 못 한 채 진행" 을 선택지로 남긴다.

`cryptography` 는 `play_upload.py` 의 `google-auth` 가 이미 끌어온다. 없으면 **종료 코드 2** 다.

ES256 의 함정은 하나다 — DER 서명을 **R‖S 고정 32바이트씩**으로 바꾸는 것.
**서명이 실제로 검증되고 변조본이 거부되는 것까지 테스트한다.**

## #39 팀 ID 를 이미 읽는 파일에서 찾지 않았다

`--team-id` 를 요구했는데 `project.yml` 안에 `DEVELOPMENT_TEAM` 이 있다. 같은 파일에서
버전·번들 ID 는 읽으면서 팀 ID 만 사람에게 복사시켰다.

```
1 --team-id   2 기존 ExportOptions.plist   3 project.yml   4 pbxproj
```

**출처를 함께 출력한다.** 여러 팀에 속한 계정에서 엉뚱한 팀으로 서명하는 것이 이 값의 실패
방식이다. 못 찾으면 어디를 찾아봤는지 알리고 중단한다 — 추측하지 않는다.

## #40 알파 채널 · ASC 버전 일치

### §4-2 알파 채널 게이트

> Images can't include alpha channels or transparencies.

`xcrun simctl io … screenshot` 은 RGBA 로 내놓는다. **촬영 단계와 업로드 단계가 분리돼 있으면
촬영한 사람은 모르고 업로드에서야 막힌다.**

**떼기 전에 무손실인지 본다.** 투명 픽셀이 있으면 배경색이 필요하고 그냥 `convert("RGB")` 하면
검게 나간다. 게이트가 둘을 구별한다.

```
0  알파 없음        1  알파 있음(무손실/배경색 필요를 구별)        2  검사 불가
```

### §4-3 ASC 버전 일치

ASC 는 앱 레코드를 `1.0` 으로 만드는데 `project.yml` 이 `1.0.0` 이면 빌드가 그 버전에 안 붙는다.
**`--export-only` 까지는 전혀 드러나지 않고** "빌드가 안 보인다" 로 나타나 엉뚱한 곳을 찾게 된다.

### 우리가 쓴 단정도 정정했다

"스크린샷 슬롯은 **계정마다 다르다**" 는 **확인하지 않은 단정**이었다. 관찰한 것은
brick-breaker 에서 슬롯이 그랬다는 것뿐이고 원인이 계정이라는 근거는 없었다.

**다만 반대편 단정으로 갈아타지도 않는다** — 기기 지원 범위 축일 가능성이 높지만 양쪽 다 한
계정씩만 봤다. 원인을 적지 않고 "조회한다" 결론만 남긴다.

## §4-5 방향 경고 — 게이트를 만들지 않는다

zen-koi 가 이슈가 아니라 **질문**으로 올렸다. "확인이 어려우면 확인 자체를 안 하는 것도 답"
이라고 물었고, 그 답을 적었다.

```
UIRequiresFullScreen   **deprecated (iOS 9.0–26.0)** — Apple 문서 실측
                       경고를 없애려고 새로 넣지 않는다
심사 반려 사유인가      **미확인**
대체 API 사용법         **미확인** (문서 페이지를 열지 못했다)
```

**판정 기준을 모르는 채 게이트를 두면 통과도 실패도 근거가 없다.** 모르는 것이 게이트 형태로
굳는 것이 이 레포가 반복해 고쳐 온 "확인 안 한 단정" 의 최악 형태다.
