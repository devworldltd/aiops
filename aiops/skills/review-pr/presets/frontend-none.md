# 프론트엔드 체크리스트 — 범용 (프리셋 미지정)

프론트엔드 스택이 `none`이거나 지원 프리셋이 없을 때 사용.

## 품질

- [ ] 컴포넌트/함수의 책임이 단일
- [ ] 중복 렌더 로직 추출
- [ ] 매직 문자열은 상수로 추출

## 접근성

- [ ] 의미 있는 HTML 태그 사용 (`<button>` 등)
- [ ] 이미지에 `alt` 속성
- [ ] 폼 요소에 `label` 연결

## 보안

- [ ] 사용자 입력을 HTML로 직접 렌더하지 않음 (XSS 방지)
- [ ] 외부 URL 이동 시 `rel="noopener noreferrer"`

## 테스트

- [ ] 렌더 + 주요 인터랙션 테스트 존재
