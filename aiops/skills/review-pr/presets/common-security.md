# 공통 보안 체크리스트 (스택 무관)

모든 리뷰에서 공통 적용된다.

## 인젝션 / 입력 검증

- [ ] SQL Injection: ORM 사용 또는 파라미터 바인딩. 문자열 연결로 SQL 구성 금지
- [ ] 명령어 주입: `subprocess`/`exec` 에 사용자 입력 직접 전달 금지
- [ ] 경로 주입: 파일 경로에 `..` 포함된 사용자 입력 사용 금지

## XSS / CSRF

- [ ] 사용자 입력을 HTML로 직접 렌더링하지 않음 (이스케이프 또는 안전한 렌더러)
- [ ] 상태 변경 API는 CSRF 토큰 또는 SameSite 쿠키로 보호

## 인증 / 인가

- [ ] 비공개 API에 인증 미들웨어 적용
- [ ] 권한 검사가 데이터 소유자 기준 (IDOR 방지)
- [ ] 멀티테넌시 프로젝트: 타 테넌트 데이터 접근 불가

## 비밀값 / 로깅

- [ ] API 키·비밀번호·토큰이 코드에 하드코딩되지 않음
- [ ] 로그에 PII·토큰·비밀번호가 평문으로 남지 않음
- [ ] 스택 트레이스가 사용자에게 그대로 노출되지 않음

## 의존성

- [ ] 신규 의존성 추가 시 명확한 필요성 (작은 유틸은 직접 구현 고려)
- [ ] 알려진 취약점 있는 버전 사용 안 함 (확인 가능한 범위 내)
