# 백엔드 체크리스트 — 범용 (프리셋 미지정)

백엔드 스택이 `none`이거나 지원 프리셋이 없을 때 사용되는 일반 체크리스트.

## 품질

- [ ] 함수/클래스의 책임이 단일하고 이름이 의도를 드러냄
- [ ] 중복 로직이 3회 이상 반복되지 않음 (DRY)
- [ ] 매직 넘버/문자열은 상수로 추출
- [ ] 사용되지 않는 import·변수·함수 제거

## 오류 처리

- [ ] 외부 I/O(네트워크, DB, 파일) 실패가 사용자에게 의미 있는 메시지로 전달
- [ ] try/except 블록이 구체적인 예외를 잡고, bare `except:` 금지
- [ ] 실패 로그에 원인 식별이 가능한 컨텍스트 포함

## 테스트

- [ ] 신규/변경 로직에 대응하는 테스트가 존재
- [ ] 테스트가 외부 의존성에 결합되지 않도록 경계 처리 (필요 시 목)
- [ ] 행복 경로 + 주요 예외 경로 커버
