UX 와이어프레임을 작성하고 저장해줘.

## 1. 입력 수집

`$ARGUMENTS`에서 ISSUE_NUMBER를 추출합니다.

### 브리프 읽기 (forge 우선)
```bash
# 이슈에서 브리프 읽기 (forge.sh 가 GitHub/Gitea 자동감지)
forge.sh issue-comments <ISSUE_NUMBER> | grep -A 1000 "📋 브리프"
```

forge 에서 읽을 수 없는 경우 `context/00_brief.md` 파일을 읽어줘.

## 2. 와이어프레임 작성

브리프를 분석하여 다음 형식으로 와이어프레임을 작성해줘:

```markdown
# UX 와이어프레임
작성자: Planning
작성일시: [오늘 날짜]
이슈: #<ISSUE_NUMBER>
선행파일: 00_brief.md
상태: DONE
---

  │       헤더 / 네비게이션    │
  ├─────────────────────────┤
  │                         │
  │       주요 콘텐츠 영역     │
  │                         │
  ├─────────────────────────┤
  │       액션 버튼 영역       │
  └─────────────────────────┘
  ```
- **상태 목록**:
  - 초기 상태 (데이터 없음)
  - 로딩 상태
  - 데이터 표시 상태
  - 에러 상태
- **주요 요소**:
  | 요소 | 타입 | 설명 |
  |------|------|------|
  | ... | 버튼/입력/목록/... | ... |

## 예외 처리

### 에러 시나리오
| 상황 | 화면 표시 | 사용자 액션 |
|------|----------|------------|
| 네트워크 에러 | 에러 배너 + 재시도 버튼 | 재시도 클릭 |

## 3. 저장

### forge 가용 시
```bash
forge.sh issue-comment <ISSUE_NUMBER> "## 🖼️ 와이어프레임

[와이어프레임 내용]"
```

### forge 불가 시
`context/02_wireframe.md`에 저장.
